SECURITY:
- Keep FINPAY_API_TOKEN only in Netlify environment variables. Never put it in index.html or send it in chat.
- The function has the four primary website mappings built in; FINPAY_OPERATOR_MAP is no longer required.
- SITE_ORIGIN may be set to the exact live website origin. If omitted, the function allows all origins.

DEPLOYMENT:
This package includes a Netlify Function. A static drag-and-drop site upload may publish index.html without building/running the Function. Deploy the folder through a Netlify-connected Git repository or Netlify CLI so the function is packaged.
After deployment, check that /.netlify/functions/finpay is available. Then test with a small amount only after confirming the API account has sufficient balance and any required IP whitelist is configured.

IMPORTANT:
A successful HTTP response only means the provider returned a response. It does NOT by itself prove recharge success. Check the provider's transaction status before telling a customer it succeeded.
